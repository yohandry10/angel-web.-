# Nuevo logotipo NEXTELCO

Fuentes: los dos PNG recién descargados en Descargas, «Logotipo corporativo NEXTELCO en azul y metal» y «Logotipo metálico premium NEXTELCO».

Preparación mediante la herramienta integrada image_gen: extracción sobre transparencia y adaptación horizontal del símbolo N, arco azul y letras NEXTELCO; versión de letras plateadas para fondos oscuros y de letras grafito para fondos claros. No se modificaron los originales.

Archivos finales: `public/media/brand/nextelco-on-dark.png` y `public/media/brand/nextelco-on-light.png`, ambos PNG RGBA de 2172 × 724. Alpha comprobado: esquinas transparentes. El SVG de presentación usa el mismo encuadre 80 155 2040 420 para ambos archivos; elimina espacio vacío sin deformar ni recortar el símbolo.
